# 引擎配置规范

每个引擎是一个 JSON 文件：`~/Library/Application Support/OCRGUI/Engines/<id>.json`（文件名须与 `id` 一致）。新增引擎 = 新增一个 JSON 文件，重启 App 或在设置里刷新即可，**核心 UI 不需要任何改动**。

## 通用字段

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | 必填 | 唯一标识（`vision` 为内置保留 id，不可删除） |
| `name` | string | 必填 | 显示名称 |
| `kind` | string | 必填 | 适配器：`builtin-vision` / `openai-http` / `json-http` |
| `enabled` | bool | `true` | 是否出现在引擎选择器中 |
| `notes` | string | — | 说明/安装提示，显示在设置界面 |
| `timeout` | number | `300` | 单次识别请求超时（秒） |
| `base_url` | string | 见下 | HTTP 类引擎必填，如 `http://127.0.0.1:8112/v1` |
| `model` | string | — | 模型名或模型目录绝对路径（支持 `~` 前缀） |
| `prompt` | string | `Text Recognition:` | openai-http 的识别提示词 |
| `fallback_prompt` | string | — | 兜底提示词：主输出退化（重复/过短，常见于图形页）时自动用它重试一次，结果标记为"纯文本兜底" |
| `api_key` | string | — | 可选，填了会带 `Authorization: Bearer` |
| `launch` | object | — | 进程托管声明；不填 = 连接已在运行的外部服务 |

## launch（进程托管）

App 在识别前先探测 `health_url`：有响应直接复用（外部启动的服务不会被 App 关闭）；没响应则按 `command` 拉起子进程并轮询直到就绪（最长 `ready_timeout` 秒）。App 退出时只停止自己拉起的进程。

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `command` | string | 必填 | shell 命令（经 `/bin/zsh -c` 执行） |
| `cwd` | string | — | 工作目录（支持 `~`） |
| `environment` | object | `{}` | 附加环境变量（如 `PADDLE_PDX_CACHE_HOME`） |
| `health_url` | string | 必填 | 健康探测地址（任意 HTTP 响应即视为存活） |
| `ready_timeout` | number | `180` | 就绪等待秒数（模型冷启动 40s+ 属正常） |
| `stop_command` | string | — | 自定义停止命令；缺省为结束子进程 |

## 三种适配器

### 1. `builtin-vision`（内置）
系统 Vision 框架。无需任何字段（`id/name/kind` 即可）。零配置、完全离线、中英文行级识别（accurate 模式）。输出：行文本 + 置信度 + 四点坐标框。

### 2. `openai-http`（OpenAI Chat Completions 兼容）
适配 `mlx_vlm.server`、本仓库 `scripts/vlm_server.py`、vLLM 等本地服务。

请求（App → 服务）：
```json
POST {base_url}/chat/completions
{
  "model": "<model>",
  "messages": [{"role": "user", "content": [
    {"type": "input_image", "image_url": "data:image/png;base64,<图片>"},
    {"type": "text", "text": "<prompt>"}
  ]}],
  "max_tokens": 4096, "temperature": 0
}
```
响应取 `choices[0].message.content`（字符串或分段数组均可）作为整页结果（Markdown/纯文本）。

### 3. `json-http`（自定义 JSON）
适配 `scripts/paddle_classic_server.py`（Paddle 经典）。

请求：`POST {base_url}/ocr`，body `{"image_b64": "<PNG base64>"}`。
响应：
```json
{"width": 800, "height": 500,
 "lines": [{"text": "…", "score": 0.99, "box": [[x,y]×4]}]}
```
输出：行级文本 + 置信度 + 四点坐标框（UI 显示坐标框 overlay 的引擎即此类）。

## 常用提示词（VLM 类引擎）

| 引擎 | prompt | 效果 |
|---|---|---|
| PaddleOCR-VL | `Text Recognition:` | 整页 Markdown（公式→LaTeX、表格结构化） |
| Xiaomi-OCR-0 | `Task: Text Extraction.` | 纯文本 |
| Xiaomi-OCR-0 | `Task: Document Parsing.` | Markdown（表格 OTSL、公式 LaTeX） |

## 应用内安装器

设置 → “添加模型…” 等价于调用 `scripts/setup_vlm_engine.sh` / `setup_mlx_engine.sh`（同一套参数：--repo/--id/--name/--port/--prompt/--fallback-prompt + 镜像环境变量），应用负责进度展示与取消，安装完成自动重载引擎目录。
